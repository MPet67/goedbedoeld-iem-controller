# Releasebeleid

De codebasis begint met de bevroren **v2.0 Release Candidate**. Een Git-tag `v2.0.0-rc.1` kan naar de initiële commit wijzen nadat deze op hardware is bevestigd.

Een GitHub Release is nog geen OTA-update: publiceer voorlopig geen automatisch te installeren firmware. Na OTA-validatie kunnen gecompileerde `.bin`-assets uitsluitend via Releases worden aangeboden.
